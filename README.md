# 🧩 Challenge Harian #00X: Pembuat Kata Acak (String Shuffler)

**Tanggal Proyek:** 2025-09-29

Ini adalah salah satu *mini-project* harian saya untuk melatih algoritma dasar dan konsistensi *coding*.

## 💡 Tujuan Proyek

Proyek ini bertujuan untuk mengacak urutan karakter dari sebuah kata (string) yang dimasukkan melalui *Command Line Interface* (CLI).

Tujuan utama dalam pengerjaan proyek ini adalah:
1.  **Latihan Logika Array:** Secara sengaja membuat fungsi sendiri untuk memotong *string* menjadi *array* karakter, daripada langsung menggunakan `string.split('')`. Tujuannya untuk menguatkan pemahaman *looping* dan manipulasi *array* dasar.
2.  **Implementasi Algoritma:** Mengimplementasikan algoritma *Fisher-Yates Shuffle* untuk memastikan hasil acak (random) yang *unbiased* dan efisien.

## ⚙️ Cara Menjalankan

Proyek ini berjalan menggunakan Node.js (JavaScript).

1.  Pastikan Node.js sudah terinstal.
2.  Jalankan file melalui CLI dengan memberikan satu kata/string sebagai argumen **kedua** (julukan teknisnya: `process.argv[2]`).

```bash
node index.js supercalifragilisticexpialidocious
# atau
node index.js pneumonoultramicroscopicsilicovolcanoconiosis
```
